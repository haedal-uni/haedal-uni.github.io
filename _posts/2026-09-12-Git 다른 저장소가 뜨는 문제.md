test 폴더에서 prac 프로젝트를 git clone했을 때 

test 폴더에서 git log를 입력하면 관련없는 git 저장소 주소가 뜬다. 

`cd prac`을 한 후에 진행을 하면 되지만 실수로 다른 프로젝트에 commit 할 수 있다.

<br>

Git은 현재 디렉토리에 .git 폴더가 없으면 상위 폴더로 계속 올라가면서 .git을 찾는다. 

즉 test 폴더(혹은 그 상위 폴더)가 이미 다른 git 저장소에 속해 있었기 때문에

prac 안으로 들어가지 않고 명령어를 실행하면 그 상위 저장소가 잡히는 것이다.

cd prac으로 들어가서 작업하면 해결되지만 실수로 상위 폴더에서 커밋을 하면 엉뚱한 프로젝트에 커밋이 남을 수 있다.

<br>

### 문제가 되는 .git 위치 찾기
```bash
cd test
git rev-parse --show-toplevel
```

<br> 

### 삭제하기 전 확인하기
```bash
git remote -v
```

<br> 

### 삭제하기
```
# git rev-parse --show-toplevel 로 찾은 그 경로로 이동
cd <문제의_경로>
rm -rf .git
```
